# PSI sample input files

Bộ file mẫu để gửi cho các team thử upload vào PSI Shared Tool.

| File | Source trên tool | Bắt buộc |
|---|---|---|
| `Product_master_sample.xlsx` | Product master | Có |
| `Purchase_PO_sample.xlsx` | Purchase / PO | Có |
| `Sales_detail_MISA_sample.xlsx` | Sổ chi tiết bán hàng (MISA) | Có |
| `Inventory_sample.xlsx` | Inventory | Có |
| `CRM_Sale_sample.xlsx` | CRM Sale | Có |
| `Target_sample.xlsx` | Target | Có |
| `Pre_order_feedback_optional_sample.xlsx` | Pre-order feedback | Không — chỉ là danh sách case đã ghi nhận |

Có thể upload các file ở các thời điểm khác nhau. Không cần upload theo thứ tự.
